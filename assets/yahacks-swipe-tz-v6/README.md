# YaHacks Swipe TZ v6

Пять экранов Telegram Mini App по ТЗ. Чёрный фон #000000, жёлтый #F5C518, спокойная типографика и тёмные карточки. Без футера, таббара и кнопок навигации. Подписи со стрелками — подсказки к жестам.

## Маршруты

| Экран | Жест | Результат |
|---|---|---|
| Главная | Вниз | Календарь: название, дата, рекомендации по роли |
| Главная | Вправо | Подбор людей |
| Главная | Влево | Свой профиль и настройки |
| Карточка человека | Вправо | Запрос в команду |
| Карточка человека | Влево | Пропуск, следующий человек |
| Карточка человека | Вниз | Команды, достижения, кейсы |
| Шапка подбора людей | Влево | Главная |
| Шапка календаря | Вверх | Главная |
| Шапка подробного профиля | Вверх | Карточка человека |
| Свой профиль | Вправо | Главная |

Возврат из подбора вынесен в шапку, чтобы не конфликтовать с отказом на карточке.

## Проверить свайпы

Распакуйте архив, откройте prototype.html в браузере. На телефоне — свайпы, на компьютере — перетаскивание мышью. Запросы имитируются локально, сервер и Telegram API не подключены. Карточки сменяют демонстрационные имена; данные, мероприятия и фото — заполнители. Настройки показаны как макет, редактирование не реализовано.

## Редактировать в Figma

Figma Desktop → Plugins → Development → Import plugin from manifest → выберите manifest.json из этой папки. Запустите **YaHacks Swipe TZ v6 — 5 screens**. Получите пять экранов 390×844: редактируемые текст, карточки, геометрия и растровые аватары. Figma-переходы жестами не подключены; работающие маршруты доступны в HTML-прототипе.

Если Figma требует id: создайте New Plugin → Run once, сохраните сгенерированный id в manifest.json и замените code.js этим файлом. Используйте новый плагин v6, а не ранее установленный v5.

Шрифт SF Pro Display при наличии, иначе Inter. Точное название шрифта в фотографии определить нельзя. PNG-превью отрисованы приближённо системным шрифтом; в Figma возможны небольшие отличия метрик.

Исходник проверен на синтаксис и выход элементов за границы. Маршруты проверены программно. Запуск в реальном редакторе Figma не проверен.
