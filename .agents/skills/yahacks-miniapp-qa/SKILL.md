# Проверка YaHacksTG

- Запусти проверки из `package.json`, применимые к правке. При наличии browser-тестов используй существующий раннер и фикстуры.
- Проверь изменённый сценарий на мобильном viewport, а при изменении компоновки ещё и на экране 390×844 и на более узкой ширине. Для свайпа проверь целевой переход, жест ниже порога, отмену и взаимодействие со скроллом. Для действий с API проверь ошибку и повторное действие, если они затронуты.
- Для регрессии в подборе отдельно проверь карточку и шапку. Свайп влево на карточке показывает следующего человека. Тот же жест в шапке возвращает на главную. Подтверди, что один жест запускает максимум один переход или запрос.
- WebApp API можно проверять в браузере с заглушкой адаптера. Если доступен тестовый запуск через Telegram, повтори затронутый сценарий в WebView. Для нативной навигации проверь BackButton, для компоновки — изменение viewport и safe area, для авторизации — запуск с действительной сессией и обработку отказа. По возможности проверь затронутое поведение на iOS и Android.
- В отчёте укажи команды, проверенные сценарии и среду, в которой получен каждый результат.
